# Exercício — Do HTML para o React Native

## App Meu Perfil Dev (Etapa 2 de 3)

Continue no projeto `meu-perfil-dev`.

1. Traduza para React Native o cartão de perfil abaixo, escrito em HTML, no `App.js`:
   - `<h1>` com seu nome, `<p>` com o cargo, `<p>` com a cidade e `<p>` com a frase `"Disponível para projetos"`.
   - `<button>` `"Entrar em contato"` com `addEventListener('click')` que mostra um `alert` com seu e-mail.

2. Guarde nome, cargo, cidade e e-mail em constantes e mostre com `{}`.

3. Crie a constante `disponivel` (`true`/`false`) e mostre o texto certo com ternário.

4. Use `style` com objetos para:
   - nome grande e em negrito;
   - cargo com outra cor;
   - um espaço (`marginTop`) antes do botão.

5. No botão, use `Button` com `onPress` e `Alert.alert` no lugar do `addEventListener`.

**Atenção:** imagens, rolagem e botões personalizados ficam para sexta.
