# Exercício — Construindo a Base: Tudo é uma Progressão

## Projeto da semana: App Meu Perfil Dev (Etapa 1 de 3)

Durante esta semana, cada aluno vai construir um app de perfil profissional, como um cartão de visitas digital. Hoje é a base: criar o projeto e ver ele rodando no celular.

1. Crie um projeto Expo chamado `meu-perfil-dev` usando o modelo `blank`.
2. Rode o projeto com `npx expo start` e abra no seu celular pelo Expo Go (ou no modo web, tecla `w`).
3. No `App.js`, troque o texto padrão por três `<Text>`: seu nome completo, a frase `"Desenvolvedor(a) Mobile em formação"` e a cidade onde você mora.
4. Mude o `backgroundColor` do container para uma cor de sua escolha.
5. Provoque o erro de texto solto fora do `<Text>`, leia a tela vermelha e corrija.
6. Tire um print do app rodando no celular e envie no Discord.

**Atenção:** guarde este projeto. Na quarta e na sexta vamos continuar construindo em cima dele.
